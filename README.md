## What Is This?

This repository contains the documentation for two related inventions designed to transform how individuals collaborate with AI:

1.  **The Phoenix Protocol:** A method to resurrect an AI chat session with full context continuity after it reaches its token limit, allowing a new session to pick up exactly where the old one left off.
2.  **Dual-Session AI Peer Review:** A method that uses two independent AI sessions to simulate an engineering code review. One session builds the solution, while the other reviews it with fresh eyes, catching bugs and assumption errors immediately.

Together, these protocols form a complete architecture for solo developers and engineers to work with AI at a much higher level of reliability and sophistication.

---

## How It Works

- **Phoenix Protocol:** Uses a structured Master Prompt and a package of Supporting Documents to initialize a new session with 100% of the prior session's context, strategies, and personality.
- **Dual-Session Review:** Two AI instances are initialized with the Phoenix Protocol. Session A develops the code or plan. Session B, having no history of the conversation, reviews the output without any prior assumptions and identifies errors that the first session missed.
